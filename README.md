📦 Amazon Sales Intelligence Dashboard

Overview

Amazon Sales Intelligence Dashboard is an interactive data analytics application built using Streamlit, Pandas, and Plotly. The dashboard provides powerful insights into Amazon product sales data, helping users analyze product performance, discounts, ratings, savings, and category trends through modern visualizations and interactive filters.

Features

📊 Interactive Analytics

- Real-time filtering and exploration of product data
- Dynamic KPI cards for key business metrics
- Category-wise sales and performance analysis
- Product ranking and comparison

📈 Data Visualizations

- Products by Category Analysis
- Discount Distribution Charts
- Rating vs Discount Scatter Plots
- Revenue by Category Analysis
- Category Performance Radar Charts
- Product Savings Analysis

🔍 Advanced Insights

- Best Value Products Identification
- Premium Product Analysis
- Most Reviewed (Viral) Products
- High Discount Product Discovery
- Category Performance Comparison

🎯 Key Metrics

- Total Products
- Catalog Value
- Average Rating
- Average Discount Percentage
- Total Customer Savings

📂 Data Management

- CSV File Upload Support
- Interactive Product Filtering
- Download Filtered Data
- Automatic Data Cleaning and Processing

Technologies Used

- Python
- Streamlit
- Pandas
- Plotly Express
- Plotly Graph Objects

Installation

pip install streamlit pandas plotly

Run the Application

streamlit run app.py

Dataset Requirements

The CSV file should contain the following columns:

- product_name
- category
- discounted_price
- actual_price
- discount_percentage
- rating
- rating_count

Business Value

This dashboard helps:

- Analyze product performance
- Track category-wise revenue
- Identify profitable products
- Monitor customer ratings
- Evaluate discount strategies
- Discover market trends

Dashboard Highlights

The Amazon Sales Intelligence Dashboard combines modern UI design with powerful analytics, enabling businesses, students, and data analysts to gain actionable insights from Amazon product datasets through an intuitive and visually appealing interface.
